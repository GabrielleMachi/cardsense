# CardSense — demonstração pessoal

Versão 0.8 adaptada para GitHub Pages. Envie os arquivos extraídos para a raiz de um repositório público. Em Settings > Pages, selecione Deploy from a branch, main, /(root) e Save.

O GitHub Pages não executa os proxies da Netlify. As consultas ao MYP Cards usam diretamente a API oficial e podem falhar se o servidor bloquear CORS. Use o cadastro manual de preços nesse caso. A integração com a LigaPokémon e a coleta automática de vendas continuam pendentes. O scanner exige HTTPS, autorização da câmera e acesso à internet para carregar o OCR e o catálogo. O histórico é local.

Esta versão é apenas uma demonstração não comercial; para assinatura ou SaaS comercial, use hospedagem apropriada.
